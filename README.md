## 安装

1. 下载上方安装 ZIP，解压得到「Codex 哨站.app」。
2. 将 App 拖入「应用程序」，打开后从屏幕顶部菜单栏进入。
3. 使用 Codex 额度功能需本机已安装 Codex，并登录自己的账号。MiniMax 和自定义监控可单独配置。

支持 macOS 13 及以上，兼容 Apple Silicon 和 Intel Mac。无需安装编译工具。

当前安装包采用临时签名，尚未经过 Apple 公证；首次打开时 macOS 可能要求确认。如被拦截，在确认下载来源后，可到「系统设置 → 隐私与安全性」查看系统提供的打开选项。
